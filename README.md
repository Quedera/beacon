# QUEDERA Beacon

> **v0.1.0** — documentation baseline. **No code yet.** Three architectural blockers (per PRD §16) gate any real build.

The central customer-facing hub for the entire QUEDERA portfolio. One place to discover **Pulse / Duet / Atlas / Beacon**, manage subscriptions, see reports, and navigate into the right product.

This repo is the canonical record of the **v1.0 PRD** as James Macmillan Wood dropped it in `#beacon` on 2026-08-16. It exists to **make the brief Discord-greppable**, give contributors a structured starting point, and surface the blockers that gate Phase 1 (Foundation).

---

## Brand position

```
QUEDERA        ← master brand (everywhere in chrome)
└── BEACON     ← hub brand (this product)
    ├── Pulse  ← ITSM maturity (separate product)
    ├── Duet   ← Service transition (separate product)
    ├── Atlas  ← SaCM/CMDB discovery (separate product)
    └── Beacon ← Executive dashboards (separate product, also hosted here)
```

**Common misconception:** Beacon is the *control centre over* the four products. It does **not** replace Pulse / Duet / Atlas operations — those remain authoritative for their specialist workflows. SENTINEL (consultant marketplace) is a separate QUEDERA product and is **not** one of these four.

See [`architecture/brand-hierarchy.md`](./architecture/brand-hierarchy.md) for the full hierarchy and UI mapping.

## Three blockers gating Phase 1 Foundation

These come straight from PRD §16 and the conversation that followed James's drop. Until they're resolved, we're documenting, not building.

1. **Pulse and Atlas are design-only.** Nothing to surface for two of the four portfolio products.
2. **No authoritative subscription / commercial API.** PRD §13 lists it as Beacon's dependency; §16 row 2 flags confirming the source system as a key risk.
3. **No identity provider is in scope per §2.2, but NFR-001 requires server-side entitlement enforcement.** Conflict that needs resolving.

See [`risks/register.md`](./risks/register.md) for the full register and what's needed to close each one.
