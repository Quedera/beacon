# Product Detail Requirements

PRD §8 — the standard product detail view.

## Sections

| Section | Example content |
|---|---|
| Identity | QUEDERA Pulse / Duet / Atlas / Beacon, product description, iconography |
| Status | Active, Trial, Expiring, Suspended, Not Subscribed |
| Subscription | Plan, renewal date, entitlement summary |
| Capabilities | Modules / features included |
| Users | Assigned users and access level, subject to permissions |
| Content | Relevant dashboards, reports, scorecards, and recent activity |
| Health | Product / service status where available |
| Primary action | Open Product / Manage Access / Contact QUEDERA |

## Standard across products

Every product gets the same section vocabulary. Difference is in content, not layout. This is what makes the IA scalable (NFR-006) — adding a fifth product doesn't add a sixth card variant.
