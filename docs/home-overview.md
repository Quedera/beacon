# Beacon Home / Overview Requirements

PRD §7 — what the Beacon home page actually contains.

## Eight required elements

- **Header**: QUEDERA + Beacon identity, customer selector / context, notifications, help, user profile
- **Portfolio summary**: number of active products, subscriptions requiring attention, key portfolio actions
- **Product cards**: Pulse, Duet, Atlas, Beacon — with product purpose, status, key metrics, primary action
- **Action centre**: renewal approaching, access request, report available, data quality issue, transition milestone
- **Executive highlights**: selected cross-product KPIs and trends
- **Recent content**: recently viewed dashboards / reports
- **Favourites**: user-selected products and reporting content
- **Quick links**: Reports & Dashboards, Products, Subscriptions, Administration

## Fits into FRs

This screen is where the §6 FRs come together visually:

- FR-001 (customer context) — header customer selector
- FR-002 / FR-003 (product catalogue + status) — product cards
- FR-013 (recently viewed) — recent content
- FR-012 (favourites) — favourites
- FR-016 (notifications) — notifications icon in header

## Phase

Phase 1 Foundation delivers the shell with customer context, navigation, and product cards. The action centre, executive highlights, and favourites move to later phases as the underlying data surfaces land.
