# Subscription Centre Requirements

PRD §9 — one commercial + entitlement view per customer, instead of forcing customer administrators to visit each product.

## What it does

- Lists every subscription associated with the customer.
- Shows product, plan / tier, status, start date, renewal / end date, and account owner.
- Highlights subscriptions requiring attention.
- Shows included entitlements and consumption where supported by the source product.
- Provides access to relevant product documentation or contact / support action.
- Supports role-based visibility so commercial information isn't exposed to unauthorised users.

## Phase

Phase 3 — Subscriptions. This whole screen is gated by §16 row 2 (Subscription source — confirm authoritative system + API contract).
